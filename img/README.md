# Photos

The page's photos are free Pexels photos listed in `photos.txt`. To change one, edit its ID
there and run the **Fetch photos** workflow on GitHub (Actions tab → Fetch photos → Run workflow).

Personal photos:

- Replace `desk.jpg` with a photo of Debbie (portrait, about 4:5). It shows in the taped polaroid beside her letter.
- Add `cover.jpg`, the real *Searching for Home* cover (2:3). It replaces the placeholder cover design.
